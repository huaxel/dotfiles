# Neovim (LazyVim) Resources

Curated, verified sources for the mission in [MISSION.md](./MISSION.md). Knowledge explainers are grounded here, not in guesses.

## Knowledge

- [:Tutor — Neovim's built-in interactive course](https://vimhelp.org/)
  Run `:Tutor` inside nvim: a hands-on ~30-minute intro to core editing (modes, motions, operators, registers). Use for: first exposure to any fundamental before I explain it.
- [Vim user manual (official) — vimhelp.org](https://vimhelp.org/)
  Authoritative reference. Use for: anything I teach — `usr_03` (motions), `usr_04` (small changes, text objects), `motion.txt`, `registers.txt`. Every explainer cites this.
- [LazyVim official documentation](https://www.lazyvim.org/)
  The distribution's own docs: keymap reference, extras list, options. Use for: anything config-specific — what a key does in MY setup, which extra enables what.
- [Book: _Practical Vim_ (2nd ed.) — Drew Neil](https://www.goodreads.com/book/show/13607232-practical-vim)
  The best book on *effective* vim — 120+ short tips on composable edits, the `.` command, macros, registers. Use for: after basics are solid; read slowly, a few tips at a time.
- [Review/ordering guide: Practical Vim (tomasino)](https://blog.tomasino.org/review-practical-vim-edit-text-at-the-speed-of-thought/)
  Explains *why* Practical Vim is for intermediates, not first-timers — helps sequence our lessons.
- [Learning Vim in 3 Steps — Bozhidar Batsov](https://batsov.com/articles/2026/02/24/learning-vim-in-3-steps/)
  A sensible roadmap (tutor → fundamentals → fluency) that matches our plan.
- [Vim Adventures (game)](https://vim-adventures.com/) / [Vimventure (game)](https://vimventure.dev/)
  Optional gamified practice for motions when drills feel dry.

## Wisdom (Communities)

- [r/vim](https://reddit.com/r/vim)
  High-traffic, well-moderated. Use for: "is this a good habit", real-world troubleshooting of fundamental questions.
- [r/neovim](https://reddit.com/r/neovim)
  Use for: Neovim/LazyVim-specific questions, plugin discussions, config advice.
