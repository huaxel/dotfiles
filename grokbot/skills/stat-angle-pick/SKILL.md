# Stat angle pick

1. Check what was already posted and how it did (recent posts, journal). Never re-suggest an angle that flopped or already ran; rest a subject that flopped twice.
2. Check today's and the next few days' fixtures and verify the dates and kickoff times from a source. Don't guess the day of a match.
3. Check the ready queue, if there is one, for items whose hook matches a fixture or a live thread. Note any that can be pulled forward.
4. Score each candidate on: named clubs or rivalries (these beat generic tables), timing (before the related match or while a thread is still live), a debatable claim, and whether the data exists or can be built quickly.
5. Define the winner as: subject, comparison set, metrics, the hook being tested, and the one caveat a critic would raise.
6. Recommend one, with one backup. Give the timing (post before kickoff X) in the user's timezone.
7. Stop at the angle. Writing the copy and managing the queue belong to the copy owner; building the chart goes to the build brief.
