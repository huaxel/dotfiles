## Findings
- `aGVsbG8=` decodes to `hello`; the test sequence is syntactically correct.
- Nushell emitted: `1b 5d 35 32 3b 63 3b 61 47 56 73 62 47 38 3d 07`, i.e. `ESC ] 52 ; c ; aGVsbG8= BEL`.
- Ghostty accepts BEL as an OSC terminator. Its portable equivalent is `printf '\\033]52;c;aGVsbG8=\\033\\\\'` using ST (`ESC \\`).
- The tracked config has no explicit `clipboard-write` setting; Ghostty's documented default is allow. `clipboard-read` is separate and only matters for OSC52 queries (`?`).
- Running the test through the coding tool did not test Ghostty: the tool captures stdout through a pipe, so Ghostty never receives/interprets the escape sequence. `pbpaste` therefore remained unchanged.
- Active config path is `~/.config/ghostty/config -> /nix/store/.../.config/ghostty/config`, generated from `config/ghostty/config`.

## Decisions
- No config change made: the test sequence and current write permission are already correct.
